# R19 — Design before implementation

## Prompt

Using the single-responsibility-principle skill, implement a feature that
lets an operator cancel a suspended payment: the payment must exist and be
in SUSPENDED status, the cancellation reason must be stored with the
payment, and a `pay.cancelled` Kafka event must be published afterward.
Create the classes you need.

## Expected

Before writing any class, the agent lists the responsibilities identified
from the requirements (for example cancellation business rule, persistence,
event publication), proposes classes with one responsibility each, assigns
behaviors and data to each, describes their collaboration (dependency
injection), explains SRP compliance, and lists unresolved questions (such as
the event payload or the behavior when publication fails). It invents no
extra requirement and does not create one class per method.
