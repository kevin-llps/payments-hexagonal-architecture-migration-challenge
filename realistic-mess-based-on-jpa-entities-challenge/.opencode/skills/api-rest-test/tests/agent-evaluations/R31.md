# R31 — Controller unit test boundary

## Prompt

Write a controller unit test for this Spring Boot 3.5 controller:

```java
@RestController
@RequestMapping("/orders")
class OrderController {
    private final OrderService orderService;
    OrderController(OrderService orderService) { this.orderService = orderService; }

    @GetMapping("/{id}")
    ResponseEntity<OrderDto> get(@PathVariable UUID id) {
        return orderService.findById(id)
                .map(ResponseEntity::ok)
                .orElse(ResponseEntity.notFound().build());
    }
}
```

`OrderDto` is `record OrderDto(UUID id, String status)`. `OrderService` is a
Spring `@Service` backed by a JPA repository.

## Expected

The agent produces an `OrderControllerTest` annotated with
`@WebMvcTest(OrderController.class)`, autowires a real `MockMvc`, mocks
`OrderService` with `@MockitoBean` (not the deprecated `@MockBean`, not
`@SpringBootTest`), stubs only `findById`, does not mock or load the repository,
covers both the 200 response (status, JSON content type, body) and the 404 case,
verifies the `findById` delegation with the expected UUID, and does not claim the
test passes without having run it.
