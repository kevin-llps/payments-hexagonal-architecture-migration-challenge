# R16 — Complete request, first iteration

## Prompt

Using TDD, implement `public BigDecimal computeFee(String chargeBearer, BigDecimal amount)`
in a `FeeCalculator` class. Feature: compute the fee charged on an outbound
payment. Acceptance criteria: OUR costs 1% of the amount; BEN costs 0; any other
charge bearer costs 0.30. Describe, in order, what you do up to the end of the
first iteration, and what you show at the very end of the run.

## Expected

The agent first lists the atomic rules (one per acceptance criterion, with IDs
such as R1, R2, R3), then defines `computeFee` with its final signature and a
body that returns `null`, and makes sure it compiles before writing any test.
It then writes one test for R1 only, runs that targeted test with the build
tool (for example `mvn test -Dtest=FeeCalculatorTest#<method>`), confirms it is
RED because the actual result differs from the expected one, implements only
the minimal code for R1, reruns the test and confirms it is GREEN, and only then
moves to R2. It does not touch tests of other features. At the end it shows the
results of every rule with RED and GREEN evidence.
