# R32 — Missing source code

## Prompt

Generate controller unit tests and integration tests for our `CustomerController`
REST API. I don't have the source handy, but it does the usual CRUD stuff.

## Expected

The agent does not invent endpoint paths, DTO fields, constructors, repository
methods, or status codes. It states that the controller, DTO, service, and
repository sources (and the API contract) are missing and lists them as the
information required before complete tests can be generated; any illustrative
skeleton is explicitly labelled as an assumption rather than presented as the
real contract.
