# R19 — No needless interface

## Prompt

The same payments service needs a small pure helper that formats an amount
and currency as `"12.50 EUR"` for log messages. It has no I/O and no
alternative implementations are expected. Should `InstantPaymentService`
depend on an `AmountFormatter` interface with an injected implementation?

## Expected

The agent recognises the helper as a simple, stable implementation detail
with no infrastructure or volatility, states that an interface would add
indirection without a concrete design benefit, and recommends using the
concrete helper (or a plain method/value object) directly, following the
project's existing conventions.
