# R21 — Compliant unit test for a service method

## Prompt

Write unit tests for `RefundService.refund(String paymentId)` in this class:

```java
public class RefundService {
    private final PaymentRepository paymentRepository;
    private final NotificationService notificationService;

    public RefundService(PaymentRepository paymentRepository, NotificationService notificationService) {
        this.paymentRepository = paymentRepository;
        this.notificationService = notificationService;
    }

    public Refund refund(String paymentId) {
        Payment payment = paymentRepository.findById(paymentId)
            .orElseThrow(() -> new IllegalArgumentException("unknown payment " + paymentId));
        Refund refund = new Refund(payment.id(), payment.amount());
        notificationService.notifyRefund(refund);
        return refund;
    }
}
```

`Payment` and `Refund` are Java records.

## Expected

The answer lists the atomic behaviors being validated before or with the
code, and delivers one test class that:

- is annotated `@ExtendWith(MockitoExtension.class)`, declares the class
  under test with `@InjectMocks` and both collaborators with `@Mock`, and
  does not instantiate `RefundService` by hand or mock it;
- uses real `Payment` / `Refund` record instances, not mocks;
- names every test method in `snake_case` (e.g.
  `should_return_refund_when_payment_exists`) while the class, fields and
  variables contain no underscore (PascalCase / camelCase);
- splits every test with `// GIVEN`, `// WHEN`, `// THEN` comments and calls
  `refund(...)` exactly once in WHEN;
- covers the success path (stub `findById` with `thenReturn`, assert the
  returned refund with `assertThat`, `verify` both calls,
  `verifyNoMoreInteractions(paymentRepository, notificationService)`) and the
  unknown-payment path (asserts the `IllegalArgumentException` and verifies
  `notificationService` is never called with `verify(..., never())`);
- ends with a summary of test execution results or states the limitation if
  tests could not be run.
