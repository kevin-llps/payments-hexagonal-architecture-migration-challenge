# R10 — Compound criteria

## Prompt

Turn these acceptance criteria into rules for a skill that renames files:

- It must rename files and log every rename.
- It must refuse to overwrite an existing file.

## Expected

The agent proposes at least three separate rule IDs: one for renaming, one for
logging each rename, and one for refusing to overwrite. No rule combines the
rename and the log into one behavior.
